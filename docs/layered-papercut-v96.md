# Layered Papercut v96 적용 기록

## 이번 변경

기존 Three.js를 유지하고 주요 환경 에셋의 실제 지오메트리를 종이 모형으로 변경했습니다.
평면 이미지를 카메라 쪽으로 돌리는 방식이 아니라, 어느 방향에서도 두께가 있는 3D 페이퍼컷 디오라마입니다.

| 대상 | 적용 내용 |
| --- | --- |
| 에이전트 집 5채 | 3중 색지 벽, 실제 창 구멍 5곳, 출입구 오림, 안쪽 창판, 접힌 겹지붕 |
| 집별 부속 지붕 | 관제탑, 작업실 차양, 정원 스튜디오의 기존 개별 실루엣을 종이판으로 유지 |
| 등대 | 16층 몸체, 6층 지붕, 같은 다각형 규격의 색 띠로 면 간섭 방지 |
| 나무와 생울타리 | 교차하는 3방향 종이판에 방향당 5겹, 생울타리 인스턴싱 유지 |
| 꽃과 바위 | 별도 오림 도형에 색상과 깊이가 다른 종이 층 적용 |
| 배 | 5겹 선체, 선체 모양의 띠, 겹지붕 선실; 부유와 승하선 노드 유지 |
| 공용 시설 | 정자, 시계탑, 수리소, 시장 차양에 같은 겹지붕 규칙 적용 |

캐릭터의 신체와 애니메이션, 크레인 등의 구조 부재는 기존 3D 형태를 유지합니다.
모든 개별 소품을 완전히 재제작한 버전은 아닙니다. 주요 건축물과 자연물에 공통 제작 규칙을 적용한 버전입니다.

## 유지한 계약

- 행성 반지름, 지형, 도로, 집의 위치와 사용자 저장 배치 키는 변경하지 않았습니다.
- 에이전트별 색과 시그니처, 집 소유권, 문 접근 좌표, 충돌 반경을 유지했습니다.
- 창 재질의 발광 상태와 움직이는 나무, 배, 등대 조명은 정적 메시와 분리했습니다.
- 여러 색지 층은 정점 색상으로 합쳐, 한 부품을 한 번의 렌더 호출로 그립니다.
- 외부 에셋 다운로드, React 전환, 물리 엔진 추가는 없습니다.
- 종이 단면을 가리던 그림자 줄무늬를 줄이기 위해 기존 그림자 맵의 적용 범위를 행성 크기에 맞췄습니다.
- 캐시 v96 및 도형 데이터 버전을 함께 올려 새 코드와 이전 도형 데이터가 섞이지 않도록 했습니다.

## 수정 위치

- `assets/papercut/contours.js`: 나뭇잎, 소나무, 선체, 바위, 꽃의 오림 외곽선.
- `src/world/paper-assets.js`: 벽, 지붕, 부조, 등대의 층 수, 간격, 두께, 색지 단면.
- `src/paper-style.js`: 공통 종이 질감과 교차형 나뭇잎.
- `src/world/harbor-kit.js`: 에이전트별 부속 지붕과 생울타리.
- `src/main.js`: 기존 에셋 팩토리와 위 공통 부품 연결.

## 검증

- 자동 테스트 66개 통과. 실제 창 구멍 광선 검사, 유한 정점과 단면 색상, 두께, 메시 병합 검사를 추가했습니다.
- 브라우저 QA: 여섯 집의 입장 안내, 서비스 패널, 결과 공간 통과.
- 전면 보행 508개 표본과 집 주변 339개 표본에서 막힌 지점 없음.
- 바다의 도보 진입 차단, 배 승하선과 육지 복귀 통과.
- 집 사이 최소 거리 6.064 유지, 후면 반구의 집 3채 유지.
- 1280 x 800 및 390 x 844 화면에서 캔버스 색상 출력과 레이아웃 확인.
- 동일 데스크톱 화면 재측정에서 이전 에셋 약 60fps, 변경 에셋 약 60fps.
  검증 세션 중 프레임 하락 구간도 관찰했으므로 이것을 실기기 최소 성능 보장으로 해석하면 안 됩니다.
  모바일 실기기와 장시간 실행은 별도 성능 검증이 필요합니다.
- 배포 전 검증, 정적 산출물 검증, diff 공백 검사 통과.

브라우저를 새로고침하면 적용됩니다. 배치 초기화는 필요하지 않습니다.
원격 배포와 커밋은 수행하지 않았습니다.
