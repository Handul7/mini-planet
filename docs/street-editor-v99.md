# v99 도로 및 집 편집 후속 개선

## 목적

v98의 중앙 순환로와 집 배치는 유지합니다. 이번 변경은 편집 후 도로와 연석이
따로 남거나 집 입구와 진입로가 어긋나는 문제를 줄이는 작업입니다.
행성 크기, 본도로 폭, 집 위치, 기존 에셋과 저장 키는 변경하지 않습니다.

## 반영 내용

- 편집기에서 도로를 그리거나 복제하면 같은 경로의 연석을 함께 생성합니다.
- 도로 삭제 시 같은 경로의 연석을 함께 삭제합니다. 도로 진행 방향이 반대여도
  점열이 일치하면 한 쌍으로 인식합니다.
- 경로가 다른 사용자 연석은 보존합니다. 같은 도로가 겹쳐 있는 경우 마지막
  도로가 삭제될 때까지 공용 연석을 유지합니다. 연석 중복 생성도 방지합니다.
- 연석을 직접 선택해서 삭제한 경우 도로 본체는 유지합니다.
- 집 회전 후 진입로와 연석 입구를 저장 전에 갱신합니다.
- 등대 이동 중에도 일반 집과 동일하게 진입로를 갱신합니다.
- 모바일 터치 취소나 창 포커스 이탈 시 드래그 상태를 정리합니다. 취소된 터치를
  새 도로 점으로 오인하지 않으며, 이동한 오브젝트는 마지막 위치를 저장합니다.
- 집 연결 검사는 소유자 이름이 아니라 실제 집 객체로 진입로를 찾습니다.
  소유자가 없는 복제 집 여러 개를 동일한 집으로 오인하는 것을 방지합니다.

## 저장 호환 및 제한

기존 저장 키 `HandulPlanet_layout_harbor_v24`를 유지하며 초기화는 필요 없습니다.
저수준 경로 복원 코드는 바꾸지 않아 실행 취소 및 저장본 불러오기 시 기존 구성이
그대로 복원됩니다. 기존 독립 경로에 연석을 일괄 추가하는 마이그레이션은 없습니다.

도로와 연석의 짝은 같은 개수의 경로점을 비교하여 판정합니다. 점을 추가하거나
일부만 수정한 사용자 연석은 자동 삭제하지 않습니다. 새로운 임의의 도로가
건물이나 바다를 통과하지 않는다는 보장은 아니므로 배치 후 검사는 필요합니다.

## 검증

- 자동 테스트 89개 통과. 신규 11개는 경로 짝 관리, 중복/공유 연석,
  도로 복제, 집 회전, 등대 이동, 터치 취소를 검사합니다.
- 실제 저장 배치: 오브젝트 26개 유지, 집 6개 연결 유지.
- 도로 중앙과 보행 가능 가장자리 1,599개 표본: 장애물 충돌 0, 수역 침범 0.
- PC 1280x800 화면 및 캔버스 출력 확인.
- 별도 localhost 테스트 주소에서 등대 추가, 회전, 실행 취소 직접 확인.
  해당 브라우저 오류/경고 로그 없음. 사용자 127.0.0.1 저장본은 변경하지 않음.

커밋 및 원격 배포는 별도 요청 시 진행합니다.
