# 개인 작업실 구현·검증 기록

기준: 2026-09-25, Mini Planet v119 (`e6a8cc3`) 기반 별도 작업 브랜치.

## 구현

- 기존 마을 화면에서 개인 작업실을 여는 `?owner=1` 모드.
- 주민·상태별 업무 필터, `default`·`rodi`·`jarvis`의 반복 일정, 로디의 확인된 실행 요약.
- 주민 선택은 담당 업무로, 로디의 집은 실행 요약으로, 자비스의 집은 일정으로 연결.
- 같은 출처의 로그인 세션을 사용하는 Python 서버와 읽기 전용 API 전달.
- 실제 컨트롤러 키는 서버의 비공개 파일에서만 읽음.
- 응답은 브라우저 메모리에만 보관하며 로그아웃·401·세션 만료 때 제거.
- 15초 freshness 계약을 적용하고 조회 실패·미확인·지난 성공 데이터를 구분.
- 인증/API 응답은 서비스 워커와 HTTP 캐시에 저장하지 않음.

## 검증

- JavaScript 테스트 343개 통과: 기존 회귀 검사, 응답 계약, freshness, 클라이언트,
  세션 경쟁 상태, 서비스 워커의 개인 API 캐시 제외 포함.
- Python 서버 테스트 15개 통과: 가짜 로컬 컨트롤러를 사용한 인증, 허용 경로,
  GET 제한, 만료·로그아웃, Host/Origin, 정적 파일 경계, 오류 응답 검사.
- 배포 전 검사 및 정적 산출물 검사 통과: 공개 파일 98개, 약 3.62 MiB.
- 브라우저에서 익명화 응답으로 로그인 성공/실패, 업무 116건, 필터, 일정 9개
  (자비스 최근 실행 오류 1개), 로디 실행 요약, 로그아웃 시 화면 제거 확인.
- 390×844 모바일 크기에서 패널 배치 확인. 브라우저 JavaScript 오류 없음.
- 제공받은 익명화 응답의 시각을 변경하지 않았으며, 미리보기는 확인 만료로 표시.
- 독립 코드 검토에서 발견한 로그아웃/재로그인 쿠키 경쟁 상태를 수정하고 회귀 테스트 추가.

## 남은 실제 연결 검증

맥미니, 실제 컨트롤러 키, 실제 업무 데이터에는 접속하지 않았습니다.
이 결과는 화면·세션 서버·응답 계약의 로컬 검증이며 실제 맥미니 연결 성공을
의미하지 않습니다. 맥미니에서 현재 컨트롤러 포트와 키 형식을 확인한 뒤
[실행 안내](owner-handoff-ko.md)에 따라 로그인·조회·로그아웃을 확인해야 합니다.

첨부파일 열기, 주민 전체 실시간 활동 판정, 대화·업무 생성·예약 변경은 포함하지
않았습니다. 현재 API가 제공하지 않는 값은 0건이나 정상 상태로 추정하지 않습니다.

## 전달 번들

`_site/`, `owner-server.py`, `docs/`만 포함합니다. 컨트롤러 키·로그인 비밀번호·
테스트용 익명화 응답·개발 서버는 번들에 포함하지 않습니다.
공개 사이트에 이 서버나 비밀 파일을 업로드하는 작업은 필요하지 않습니다.
