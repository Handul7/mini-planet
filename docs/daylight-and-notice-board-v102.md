# v102: 낮 시간 렌더링 안정화와 마을 게시판

## 범위

- 낮에 이동할 때 보이는 번쩍임을 줄이는 렌더링 변경.
- 중앙의 기존 장식 게시판을 실제 글을 표시하는 게시판으로 교체.
- 집, 도로, 행성 크기와 사용자 지정 배치를 유지. 커밋 및 원격 배포는 하지 않음.

## 1. 번쩍임 분석과 적용

확인한 위험 요인은 후처리 화면의 안티앨리어싱 부재, 얇은 종이 층의 자기 그림자, 밝은 면에 걸리는 bloom이다. 사용자가 겪은 현상을 단일 원인으로 확정하거나 모든 기기에서 완전히 없앴다고 단정하지 않는다.

| 파일 | 변경 | 목적 |
| --- | --- | --- |
| `src/render-stability.js` | WebGL2에서 최대 2샘플 MSAA 후처리 타깃 | 이동 중 가는 윤곽선의 계단/깜박임 완화 |
| `src/render-stability.js` | `layered-cut-card` 메시의 receiveShadow 해제 | 가까운 종이 층끼리 생기는 자기 그림자 완화 |
| `src/main.js` | bloom threshold 0.92에서 1.40 | 밝은 종이 면 전체가 과하게 발광하는 현상 완화 |

종이 오브젝트의 그림자 투사는 유지하고 바닥의 그림자 수신도 유지한다. WebGL1은 MSAA 0으로 폴백한다. 기존 품질 조절기는 유지한다. 이동/시점 회전 중 직접 확인했지만 연속 영상 기반 깜박임 정량 비교는 하지 않았다. 잔여 현상이 있다면 같은 시간대와 위치에서 그림자/bloom/MSAA를 각각 끄는 비교가 다음 진단 단계다.

## 2. 마을 게시판

- 기존 resultBoard를 교체하므로 기본 배치에서 게시판이 중복되지 않는다.
- 기존 기본 위치만 중앙 광장 가장자리로 조정하고, 사용자가 옮긴 게시판은 보존한다.
- 녹색 프레임, 얇은 종이 면, 구리색 덮개로 기존 페이퍼컷 팔레트와 연결한다.
- 3D 게시판 또는 우측 게시판 아이콘으로 열기.
- 제목/본문 편집, 취소, 저장, 기본 글 복원, JSON 내보내기.
- 3D 면에는 미리보기를, 대화상자에는 전체 글을 표시한다.
- 저장소 버전 v26으로 이행하며 v25와 이전 키는 보존한다.

### 저장과 공개 범위

**화면에서 저장하는 글은 해당 브라우저에만 저장된다. 다른 방문자나 다른 기기로 자동 공유되지 않는다.**

모든 방문자에게 보여줄 기본 글은 `config/village-board.json`의 `title`, `body`로 관리한다. 화면의 JSON 내보내기로 만든 내용을 이 파일에 반영한 후 사이트를 배포한다. 로컬 수정본이 있는 브라우저는 '기본 글로 복원'을 눌러 공개 기본 글로 돌아갈 수 있다.

실시간 공개 글 수정은 이번 범위에 포함하지 않았다. 추후 추가하려면 관리자 인증, 서버 저장소, 쓰기 권한 검증이 필요하다. 공개 사이트에서 임의 방문자가 전체 공지 내용을 덮어쓰는 API는 만들지 않았다.

### 입력과 안전장치

- 제목 최대 48자, 본문 최대 600자. 공백뿐인 저장 거부.
- 사용자 내용은 textContent/value/canvas 텍스트로만 출력한다. HTML 실행 없음.
- 저장소 접근 실패 시 입력 유지와 오류 안내.
- 모달이 열린 동안 이동/점프/상호작용 및 게임패드 입력 차단.
- 기본 native dialog의 포커스 제한과 닫기 후 포커스 복귀.

## 3. 검증 결과

- Node 테스트 109개 통과. 입력 정규화, 줄바꿈, 리본/배치 회귀, 종이 그림자, MSAA 폴백 포함.
- 데스크톱 1280 x 800, 모바일 390 x 844 화면 확인.
- 낮/맑음 환경에서 이동과 카메라 회전 확인. 캔버스 비어 있지 않음.
- 모바일 게시판 편집창 가로 넘침 없음, 화면 중앙 정렬 확인.
- 한글 여러 줄과 HTML 형태 문자열 저장, 새로고침 후 유지 확인. 테스트 글은 기본 글로 복원 완료.
- 저장된 레이아웃 27개 오브젝트 유지. QA의 배치, 도로, 보행, 물 진입 차단, 승하선 검증 통과.
- 기존 승하선 QA가 바다 한가운데 저장된 배에서도 즉시 하선을 기대하던 전제를 수정. 필요시 검증 중에만 해안 정박 위치를 사용하고 finally에서 원래 배/플레이어 상태를 복원한다. 실제 저장된 배 위치는 변경하지 않는다.
- 모바일 최종 관측 약 60fps, 앞선 장시간 세션에서는 약 35fps 관측도 있어 성능 보장은 하지 않는다. 테스트 장치는 실제 모바일 기기가 아닌 브라우저 뷰포트다.

## 4. 후속 제안

1. 동일한 위치/시간대에서 실제 사용 중 남은 번쩍임을 확인한 뒤 추가 조정한다.
2. 실제 휴대폰에서 발열과 장시간 프레임을 확인하고, 필요하면 최저 품질에서 MSAA를 끄는 정책을 검토한다.
3. 서버 연동 시 게시판 읽기는 공개, 수정은 관리자 전용으로 분리한다.
4. 추가 장식물 증설보다 현재 공용 공간과 공지 가독성을 유지한다.
