# Mini Planet v105 행성 배치 검토 보고서

작성일: 2026-09-11  
대상: 현재 브라우저의 저장된 배치 및 v105 기본 배치  
범위: 지형과 건물의 공간 관계, 기준점, 집 사이 거리, 도로와 보행·항해 동선, 원경 구도만 평가합니다.

## 1. 결론

현재 행성은 **중앙 광장과 항구를 중심으로 여러 주거 구역이 구면을 따라 퍼진 작은 항구 마을**입니다. 집이 한곳에 몰린 초기 배치에서는 벗어났습니다. 다만 사방에서 비슷한 수준으로 읽히는 마을은 아직 아닙니다. 정면에는 중심이 있지만 후면에는 그에 대응하는 공용 중심이 약합니다.

문제의 우선순위는 집 사이의 절대 거리보다 **구역 사이에 무엇이 있고, 어디로 이어지며, 어느 방향을 보고 있는지 알아보기 어려운 구간**입니다. 행성을 다시 줄이거나 빈 땅에 소품을 채우는 일보다 기존 공용 공간의 위치와 접근부를 먼저 다듬는 것이 타당합니다.

이번 작업에서는 이 판단을 근거로 집·도로·공용 공간을 재배치하지 않았습니다. 아래 제안은 후속 배치 변경을 위한 지시입니다.

## 2. 확인 방법과 한계

- 실제 저장 배치로 정면·서쪽·후면·동쪽 관제 시점을 확인했습니다. 별도로 Argos의 등대 섬과 북극 장미 주변을 가까이 확인했습니다.
- 실행 중인 장면에서 추출한 좌표와 경로 표본을 코드의 기본 배치와 대조했습니다.
- 현재 저장 배치는 점형 오브젝트 27개, 기본 배치는 25개입니다. 저장 배치에는 중앙 광장 좌우의 테라스 두 개가 더 남아 있고, 배 위치도 기본 배치와 다릅니다. 바닥·도로 메시 수를 뜻하는 숫자는 아닙니다.
- 아래 거리는 `행성 반지름 × 두 방향 벡터 사이의 각도`로 구한 **구면 중심 간 최단 거리**입니다. 미터가 아니며 장애물과 길을 따르는 실제 보행 거리도 아닙니다.
- 도로 길이는 스플라인 표본을 누적한 근사값입니다. 전체 보행 동선을 직접 걸어 완주한 검증과는 구분합니다.
- 남극 전체를 위에서 내려다보는 별도 시점은 확인하지 않았습니다. 남부 공간 관련 판단은 좌표와 지형 정의를 함께 읽은 추론임을 명시합니다.

## 3. 행성 규모와 지형

| 항목 | 현재 값 | 배치 해석 |
|---|---:|---|
| 반지름 | 7.47 | 지금 판단의 기준 단위 |
| 지름 | 14.94 | 집 폭 약 2.1~2.2와 비교하면 작지 않은 구면 |
| 대원 둘레 | 약 46.94 | 반대편 집은 한 화면에 함께 들어올 수 없음 |
| 구 표면적 | 약 701.21 | 실제 사용 가능한 평면 면적이 아님 |
| 전역 해양 판정 표본 | 약 42.6% | 카메라 화면의 파란색 픽셀 비율과는 다름 |
| 전역 육지 판정 표본 | 약 57.4% | 육지가 있다고 모두 생활권으로 읽히지는 않음 |

바다가 지나치게 넓어 보이는 장면은 전역 비율만의 문제가 아닙니다. 후면과 동쪽 시점은 아래쪽 바다가 넓게 드러나고, 육지의 주요 건물은 구면 가장자리로 밀립니다. 그래서 중앙의 비어 있는 땅과 아래의 바다가 한꺼번에 강조됩니다.

반대로 정면은 중앙 광장, 도로, 항구의 연속으로 비교적 많이 채워져 보입니다. 따라서 **전역 육해 비율을 다시 바꾸는 것만으로 시점별 불균형은 해결되지 않습니다.**

## 4. 기준점과 공간의 읽는 순서

이 보고서의 정면은 기본 관제 카메라가 보는 중앙 광장·주 항구 방향입니다. 동서 표기는 이 방향을 기준으로 한 행성 좌표의 상대 위치입니다.

| 기준점 | 위치와 역할 | 현재 판단 |
|---|---|---|
| 중앙 운영 광장 + 운영 비콘 | 정면의 중심. 두 오브젝트는 같은 중심을 공유 | 행정·운영 중심으로 가장 명확함 |
| 주 항구 | 중앙 광장 아래쪽 해안 | 바다로 이동하는 출발점이어야 하나 배와 접근로의 읽힘이 약함 |
| Rodi 집 | 중앙 광장 위쪽, 북극 가까이 | 중앙 구역의 북쪽 종착점으로 잘 읽힘 |
| B-612 장미 | 실제 북극 `(0, 1, 0)` | 지리적 기준은 분명하지만 Rodi 집과 가까워 사유 정원처럼 읽힘 |
| Argos 등대 | 중앙 광장에서 거의 반대편인 남쪽 섬 | 별도 항해 목적지로 구분되는 강한 기준점 |
| 후면 공용 공간 | 현재 Ludwig 구역 가까이에 정자 | 후면 전체의 중심보다는 Ludwig 집 부속 공간처럼 읽힐 여지가 있음 |

중앙 광장과 지리적 북극은 서로 다른 기준입니다. 둘을 같은 중심처럼 취급해서 도로를 재배치하면 정면 편중이 다시 생길 수 있습니다. **생활의 중심은 광장, 방향의 기준은 북극, 바다의 목적지는 등대**로 역할을 구분하는 편이 좋습니다.

## 7. 동선 구조

### 7.1 현재의 뼈대

```text
                          B-612 장미
                              |
                           Rodi 집
                              |
Jarvis 구역 ----- 서쪽 길 -- 중앙 광장 -- 동쪽 길 ----- Yul 구역
    |                         |                         |
    |                       주 항구                     |
    |                    생활 / 물류 부두               |
    |                         :                         |
Ludwig 구역 -------- 후면 고지대 길 ----------- Anne 구역
                              :
                       바다를 통한 이동
                              :
                         Argos 등대 섬
```

위 도식은 연결 관계를 설명한 것이며 평면 지도나 실제 항로는 아닙니다. 장미와 Rodi 사이에도 배치 관계와 별개로 독립된 접근 동선을 확인해야 합니다.

육지의 기본 구조는 `중앙 광장 → Jarvis → Ludwig → Anne → Yul → 중앙 광장`으로 돌아오는 순환형입니다. Rodi는 북쪽의 짧은 가지, 주 항구는 남쪽의 가지입니다. Argos는 보행 순환로가 아니라 바다로 분리된 별도 목적지입니다.

| 구간 | 근사 길이 | 판단 |
|---|---:|---|
| 중앙 광장 서쪽 가지 | 3.79 | 중앙에서 서부 구역으로 이어지는 길 |
| 중앙 광장 동쪽 가지 | 3.25 | 중앙에서 동부 구역으로 이어지는 길 |
| 중앙 광장 남쪽 항구 가지 | 2.16 | 항구 도착의 시각적 마무리가 중요 |
| 중앙 광장 북쪽 Rodi 가지 | 0.97 | 짧고 직관적인 종착 동선 |
| 서해안에서 Jarvis까지 | 3.96 | 서부 생활권 연결 |
| 동해안에서 Yul까지 | 4.14 | 동부 생활권 연결 |
| Jarvis–Ludwig–Anne–Yul 고지대 경로 | 18.07 | 가장 긴 연속 생활권 경로. 중간 공용 목적지가 약함 |
| 주 해안 데크 전체 | 13.16 | 길이는 충분하지만 승선부의 위계가 약함 |

중앙의 닫힌 경로 데이터는 현재 광장 면을 구성하는 데에도 쓰이므로, 이를 별도의 원형 산책길처럼 중복 계산해서는 안 됩니다.

현재 육지 도로 연결 표본은 이어져 있지만, 이것만으로 길이 눈에 자연스럽게 이어진다고 볼 수는 없습니다. 특히 정면의 광장→항구 길 끝에 지면색 띠가 보여 목재 데크와 끊어진 것처럼 느껴집니다. 길을 전체적으로 넓히는 대신 이 접속부의 위치·높이·바닥 경계만 먼저 맞춰야 합니다.

### 7.3 현재 저장 배의 위치

저장 배는 주 승선 부두에서 약 6.28 떨어진 남서쪽 바다에 있습니다. 이 거리는 보행 금지인 바다에서 출발해야 하는 사용자가 배를 찾고 접근하는 데 불리한 배치입니다. 기본 배치와 저장 배치가 다르므로 기본값만 수정해 해결했다고 판단하면 안 됩니다.

후속 작업에서는 사용자 저장 배를 자동 덮어쓰기 하지 말고, 현재 배 위치를 보존한 상태에서 승선 가능한 도킹 위치를 확인한 뒤 재배치 여부를 결정해야 합니다. 배를 장식용으로 남겨둘지 실제 승선용으로 쓸지도 배치의 역할상 구분되어야 합니다.

## 8. 멀리서 바라본 구도

| 시점 | 잘 읽히는 점 | 어색한 점 | 배치 판단 |
|---|---|---|---|
| 정면 | 중앙 광장, 북쪽 Rodi, 아래 항구의 축 | 넓은 원형 광장과 방사형 가지, 좌우 테라스의 반복이 도식적으로 보임 | 구조는 명확하나 좌우 대칭을 완화할 여지가 있음 |
| 서쪽 | Jarvis와 시계 부스, 정자와 항구 쉼터가 순서대로 보임 | 장미가 Rodi 집 정원처럼 보임 | 네 방향 중 생활 공간의 연속성이 상대적으로 좋음 |
| 후면 | Ludwig와 Anne이 서로 다른 구역으로 구분됨 | 두 집은 양끝으로 밀리고 중앙 잔디가 크게 드러남. 중앙 광장과 항구가 보이지 않음 | 가장 먼저 개선할 시점. 후면 공동 목적지가 필요함 |
| 동쪽 | Yul과 Anne의 마당 경계가 구분됨 | 위쪽 가로지르는 길과 중앙 잔디가 넓게 드러남. 건물이 좌우 가장자리로 밀림 | 집을 더 벌리기보다 길과 중간 공간의 관계를 다듬을 것 |
| 등대 집중 시점 | 한 섬에 하나의 수직 기준점이 서 있어 명료함 | 본토와의 항해 출발·도착 관계는 이 장면만으로 읽기 어려움 | 섬 자체는 유지하고 주 항구와의 관계를 보완할 것 |

넓은 여백은 모두 결함이 아닙니다. 바다와 해안 여백은 섬을 분리해 보여주고, 집 사이 여백은 각 에이전트의 독립성을 만듭니다. 문제는 **목적지 사이에 끼어 있지만 이동의 방향도, 머무를 이유도 읽히지 않는 잔디 공간**입니다.

남쪽 고위도에는 점형 오브젝트 중심이 거의 없습니다. 현재 좌표에서 남위 약 44도 아래에는 중심점이 없지만, 이것은 건물·바닥 메시가 전혀 없다는 뜻이 아닙니다. 해당 구역을 모두 개발해야 한다는 근거로도 사용할 수 없습니다. 남극 전용 원경 확인 후 자연 보존 구역으로 남길지 판단하는 것이 맞습니다.

## 9. 후속 배치 변경 우선순위

### P1. 후면 공용 중심을 먼저 정리

기존 정자는 Ludwig에서 약 2.84 떨어져 있습니다. Ludwig의 부속 정원처럼 보이지 않도록, Ludwig–Anne 사이 후면 경로의 중간 구간으로 옮기는 안을 우선 검토합니다.

새 정자나 집은 추가하지 않습니다. 경로 중간의 구면 방향을 후보로 삼되 도로 한가운데 놓지 말고, 길 옆의 작은 진입 공간으로 배치합니다. 정확한 좌표는 지형·문 방향·보행 여유·원경 가림을 확인한 후 결정합니다. 정면 광장과 같은 크기의 두 번째 광장을 만드는 안은 피합니다.

완료 기준: 후면 시점에서 두 집 외에 공동 목적지가 하나 읽히고, 두 집의 진입로는 서로 독립적으로 보이며, 정자가 도로를 막지 않아야 합니다.

### P1. 주 항구 접근부와 승선 위치 정렬

중앙에서 내려오는 길 끝과 해안 데크의 접속을 먼저 맞춥니다. 생활 항구의 승선 게이트·짧은 부두·배가 한 장소로 읽히도록 확인합니다. 오른쪽 크레인과 화물선은 물류 구역으로 남겨 승선 출발점과 혼동하지 않게 합니다.

완료 기준: 중앙 광장에서 내려왔을 때 길의 끝, 부두 입구, 탈 배가 같은 공간에서 이어지고, 바다를 걸어야 배에 닿는 배치를 만들지 않아야 합니다. 저장 배치에서도 별도로 확인합니다.

### P2. 장미를 독립된 상징 장소로 구분

북극 위치는 유지합니다. Rodi 집도 우선 이동하지 않습니다. 장미의 작은 바닥 영역과 접근 방향을 Rodi의 집 앞 마당과 구분하는 것이 먼저입니다. 장미와 집 사이를 소품으로 채우지 말고 두 장소 사이의 여백을 남깁니다.

완료 기준: 근접 시점과 동서 원경에서 장미가 Rodi 집의 부속물처럼 겹치지 않고, 집에 들어가지 않아도 접근하는 별도 장소로 읽혀야 합니다.

### P2. 중앙 광장의 반복 구조 절제

저장 배치에 남은 좌우 테라스를 각각 어떤 목적지로 쓰는지 확인합니다. 역할 없는 테라스라면 한쪽 또는 둘 다 제거하는 안을 비교합니다. 중앙 광장의 외곽과 길이 만나는 모양은 유지하되, 이유 없는 좌우 대칭을 강화하지 않습니다.

완료 기준: 중앙 비콘·게시판·항구 방향이 먼저 읽히고, 테라스가 시선을 분산시키지 않아야 합니다. 기본 배치와 저장 배치의 차이를 숨기지 않습니다.

### P3. 남부 여백은 마지막에 결정

앞선 항목 적용 후 남극을 포함해 다시 여러 방향을 확인합니다. 자연 지형의 여백으로 읽힌다면 유지합니다. 여전히 사용하지 않는 육지가 화면 대부분을 차지한다면 그 구역의 해안 형태를 국소 조정하는 안을 검토합니다.

행성 전체 축소는 마지막 선택입니다. 반지름만 줄이면 건물 간 거리, 해안 폭, 부두와 배 간격, 길의 상대 폭까지 함께 달라집니다. 현재 충분히 분산된 여섯 집을 다시 압축할 이유는 아직 부족합니다.
