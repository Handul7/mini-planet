- 여섯 집의 좌표·크기·소유 에이전트. 집 사이 거리도 동일.

- 기존 육지 순환 동선과 배로만 접근하는 등대 섬.
- 기존 장미의 위치와 대사.

## 저장 배치 보호

기본 배치와 저장 배치에 동일한 배치 함수를 적용합니다. 저장 배치를 변경하기 전에는 원본을 기존 백업 목록에 `before-composition-v106` 사유로 저장합니다. 백업 또는 레이아웃 저장에 실패하면 기존 배치를 유지합니다.

보정은 알려진 기존 좌표와 형태에만 적용합니다. 사용자가 따로 옮긴 정자·배·테라스·장미 바닥, 다른 선착장 및 길은 유지합니다. 정자 후보지에 다른 오브젝트가 가까우면 이동을 보류합니다. 이관은 한 번 적용하며, 함수 자체도 반복 실행해 중복 길이 생기지 않도록 만들었습니다.

브라우저마다 저장 배치가 다릅니다. 공개 사이트 방문자의 임의 편집 배치까지 새 기본 배치로 초기화하지 않습니다.

## 확인 결과

- 로컬의 실제 저장 배치: 점형 오브젝트 27개 → 25개.
- 정자 진입로: 약 1.82 월드 단위, 길 연결·보행 여유 확인.
- 장미 독립 접근로: 약 4.51 월드 단위. 기존 서쪽 고지대 길에 연결.
- 항구 접근 도로: 약 2.16 → 2.32 월드 단위.
- 도로 중심과 보행 가장자리 1,758개 표본: 충돌 0, 바다 침범 0.
- 실제 저장 배치의 주 부두 승선, 등대까지 항해, 상륙, 재승선, 귀항, 하선, 육지 복귀 검사 통과.

## 배치 판단

후면에 정자가 하나의 공동 목적지로 놓이면서 기존의 '두 집 사이 큰 빈 잔디' 구도가 완화됐습니다. 정면에서는 역할이 겹치던 테라스가 빠져 중앙 광장과 항구 방향이 더 단순해졌습니다.

북극 장미는 접근 방식과 바닥 영역이 분리됐지만, 정면과 정확한 후면에서는 구면 투영 때문에 Rodi 집과 시선이 겹칠 수 있습니다. 집을 다시 옮기지 않는 범위의 개선이며, 모든 각도에서 두 실루엣이 완전히 분리됐다고 판단하지 않습니다.

남극에는 넓은 자연 지형이 남습니다. 모든 표면을 도시로 채운 상태는 아닙니다. 현재는 북쪽 분산 마을·정면 항구·후면 공용 공간·독립 등대라는 구조를 유지하는 방향으로 마무리했습니다.
