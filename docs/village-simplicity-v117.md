# v117 배치 간소화 검토

## 판단

v116에서 유휴공간을 채우려고 추가한 동·서쪽 녹지 포켓은 기대와 달리
작은 장식 구역을 더 나누어 보이게 했다. 빈 공간의 면적보다 집, 길,
공용 공간이 한눈에 구분되는지가 우선이다.

- 관제 모드에서 직접 드래그 회전과 축소로 앞·옆·뒤 구도를 관찰했다.
- 탐험 모드에서는 키보드로 광장 주변을 이동하고 카메라를 돌려 관찰했다.
- 모든 동선을 수동 완주한 것은 아니다. 집 왕복과 항구 여정은 별도 런타임 검사로 검증했다.
- 원경의 작은 나무 묶음과 녹지 외곽선이 독립된 장식처럼 눈에 띄었다.
- 가까이에서는 광장, 집, 게시판, 항구가 이미 시각적 정보를 충분히 제공한다.

## 적용

- 기본 동·서쪽 `paperGrove` 2개와 `west.walk-garden`, `east.walk-garden` 바닥 2개 제거.
- 배치 오브젝트 31개에서 29개, 나무 군집 5개에서 3개로 감소.
- 항구 매대 분산, 해안 소나무 이동, 남쪽 기존 녹지의 분산 배치는 유지.
- 집 6개, 도로 폭·경로, 공용 시설, 장미, 등대, 바다 비율은 변경하지 않음.
- 라이브러리나 에셋 파일, 실행 중 반복 작업을 추가하지 않음.

## 저장 배치 보호

`migrateVillageSimplicity`는 v116 기본 장식과 좌표·방향·크기·속성이
일치하는 완전한 한 쌍만 제거한다. 이동·회전·색상·외곽선 변경,
개별 삭제 또는 중복 배치가 있으면 해당 쌍을 보존한다.
기존 백업 후 저장 절차와 v117 일회성 표식을 사용한다. 초기화는 필요 없다.

## 검증

- Node 테스트 291개 통과. 사용자 편집 보존, 반올림 좌표, 멱등성, 백업 순서 포함.
- 배포 전 검사, 정적 배포본 검사 통과. 공개 파일 94개, 약 3.56 MiB.
- 저장 배치: 도로 12개, 보행 표본 2,433개에서 막힘·수역 침범 없음.
- 일반 집 5개 왕복, 등대 포함 항구 여정, 도보 입수 차단 검사 통과.
- 장면 메시 581개에서 569개, 렌더 배치 583개에서 571개로 감소.
- 1280×900, 390×844 화면 확인. 캔버스 색상 표본 44개·33개, 모바일 가로 넘침 없음.
- 검증 중 브라우저 경고·오류 없음. 자동 기능 검사는 미적 완성도 점수가 아니다.

새 시설이나 장식 수를 늘리는 대신 현재 여백을 유지한다.
추가 미세 조정이 필요하면 길·마당 경계의 시각적 강도를 먼저 비교한다.
이번 작업에서는 그 범위까지 변경하지 않았다. 커밋·원격 배포는 하지 않았다.
