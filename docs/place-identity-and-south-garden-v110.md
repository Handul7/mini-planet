# v110 장소 구분 및 남부 배치 개선

## 검토 범위

- 현재 v109 저장 배치, 설정집, 실제 탐험 화면을 기준으로 검토했습니다.
- 엔진 교체나 에이전트 연결 변경 없이 배치, 건물 형태, 선착장과 산책 동선을 수정했습니다.
- 이미 만족하신 밀도와 레이어드 페이퍼컷 표현을 유지하는 것이 우선입니다.

## 확인된 문제와 수정

### 장미와 로디 집

기존 로디 집은 북극 장미와 중심 간 구면 거리가 약 2.12였습니다. 건물 폭과 장미 받침을 고려하면 걸어갈 때 같은 구역에 붙어 있는 인상이 강했습니다.

- 장미는 정북 `(0, 1, 0)`에 그대로 두었습니다. 나침반 기준도 유지했습니다.
- 로디 집을 중앙 광장 쪽으로 옮겨 중심 간 거리를 약 3.75로 늘렸습니다.
- 기존 기본 진입로와 앞마당을 함께 옮기고 문이 광장을 향하도록 맞췄습니다.
- 다른 다섯 에이전트 집의 위치는 유지했습니다. 전체 집 사이 최소 거리는 약 6.064입니다.

수치는 Three.js 장면 단위이며 현실의 미터 단위로 확정한 값은 아닙니다. 행성 반지름 7.47은 변경하지 않았습니다.

### 등대와 남부 빈 땅

기존 등대에 보행 데크는 있었으나, 배를 대는 곳으로 읽히는 형태와 표식이 약했습니다. 등대 앞 남부 땅도 목적지나 접근 동선이 없어 방치된 공간처럼 보였습니다.

- 등대 데크 끝에 T자 접안부와 두 개의 계류 기둥, 작은 등불을 추가했습니다.
- 남부 땅에 별도 선착장, 진입 산책로, 닫힌 순환 산책로를 만들었습니다.
- 정원 중심에는 종이 바람개비 형태의 정적 조형물 하나를 배치했습니다. 바람 시뮬레이션이나 별도 상시 애니메이션은 추가하지 않았습니다.
- 외곽에는 종이 수목 군락 세 곳만 배치했습니다.
- 등대와 남부를 연결하는 육교는 만들지 않았습니다. 바다 이동에는 여전히 배가 필요합니다.

추가된 일반 배치 오브젝트는 총 6개입니다. 계류 표식 2개, 조형물 1개, 수목 군락 3개이며 군락은 여러 나무 메시를 묶은 하나의 편집 오브젝트입니다. 기존 공용 정자와 항구 쉼터는 유지했습니다.

### 에이전트별 건물

기존에는 같은 집 몸체와 박공지붕에 작은 장식만 달라, 걸어 다닐 때 건물의 차이가 약했습니다. 공통 출입구 크기와 배치 기능은 유지하고 지붕과 입면을 구분했습니다.

| 에이전트 | 적용한 구분 |
| --- | --- |
| 로디 | 신호탑이 있는 지휘실 형태 유지, 광장 방향으로 이전 |
| 자비스 | 계단식 평지붕, 정돈된 수직 프레임, 지붕에 붙는 기록 다이얼 |
| 율 | 톱니형 채광 지붕과 입구 차양을 갖춘 공방 |
| 루드비히 | 둥근 아치형 지붕, 세로 창살을 갖춘 서재 |
| 앤 | 초록 박공지붕과 테두리, 전면 베란다, 창가 꽃 상자 |
| 아르고스 | 등대 정체성 유지, 접안 시설 보강 |

앤의 초록 지붕과 자비스의 기술 운영실이라는 설정을 반영했습니다. 외부 캐릭터의 로고나 원본 모델을 가져온 것은 아닙니다. 에이전트 역할, 서비스 연결, 상태 표시 계약은 변경하지 않았습니다.

## 저장 배치 보호

- 기본 위치에 있는 로디 집만 자동 이동합니다. 직접 옮기거나 돌려 놓은 집은 보존합니다.
- 새 위치에 기존 소품이 있으면 로디 자동 이전을 건너뜁니다.
- 기본 모양과 일치하는 앞마당과 진입로만 함께 이동합니다. 직접 수정한 꼭짓점은 유지합니다.
- 앤의 지붕은 이전 기본 색상일 때만 바꿉니다. 사용자 지정 색상은 유지합니다.
- 직접 바꾼 등대 데크에는 T자 접안부를 자동 덧붙이지 않습니다.
- 남부 예정지 근처의 사용자 배치나 경로가 감지되면 정원 자동 추가를 건너뜁니다. 이는 간단한 근접 검사이며 모든 임의 지형의 겹침을 완전히 판정하는 기능은 아닙니다.
- v110 적용 전 배치를 기존 백업 기능으로 보관한 뒤 저장합니다. 초기화는 필요 없습니다.
- 새 소품은 기존 편집 팔레트에 등록되어 위치, 회전, 크기를 수정할 수 있습니다.

## 검증

- 기본 배치와 실제 저장 배치 모두 브라우저 `qaReady=pass` 확인.
- 다섯 집의 실제 이동 함수 기반 출입 왕복 통과.
- 도로 12개, 중앙과 보행 가장자리 2,310개 표본에서 충돌 및 수역 침범 0.
- 본항 출발, 등대 상륙 및 출입, 남부 상륙 및 순환 산책, 재승선, 본항 복귀까지 16단계 모두 통과.
- 초기 산책로의 조형물 충돌을 발견해 길 모양을 수정했습니다.
- 등대의 바다 진입 검사점은 확장된 접안 데크 밖으로 옮겼습니다. 바다 보행 제한을 완화한 것이 아닙니다.
- 1280x900 데스크톱과 390x844 모바일에서 화면과 비어 있지 않은 캔버스 픽셀을 확인했습니다. 모바일 검증은 뷰포트 검사이며 실제 휴대전화 성능 보장은 아닙니다.
- 브라우저 경고 및 오류 없음. 자동 테스트, 배포 전 검사와 정적 배포본 검사 실시.
- 정적 배포본 88개 파일, 약 3.52 MiB. 새 라이브러리나 외부 에셋 다운로드 없음.

## 남겨 둔 여백과 한계

행성 전체를 건물로 채우지는 않았습니다. 북쪽은 장미와 주거지, 중앙은 광장과 본항, 후면은 서재와 정원, 남쪽은 등대와 배로 찾아가는 정원이라는 구분을 강화했습니다. 잔디 여백과 해안은 여전히 남습니다.

이번 변경은 오픈월드 전체의 콘텐츠 완성을 의미하지 않습니다. 새 정원에 대화나 이벤트를 추가하지 않았으며, 건물 내부 기능과 Hermes 연결 검증도 이번 범위에 포함하지 않았습니다. 실제 사용감은 v110에서 등대와 남부 정원을 연속으로 방문해 최종 판단하는 것이 좋습니다.

## 주요 파일

- `src/main.js`: 집 지붕 구성, 선택적 배치 이전, 선착장과 산책로, 왕복 검사.
- `src/world/harbor-kit.js`: 에이전트별 건축 형태.
- `src/world/paper-assets.js`: 박공지붕/평지붕에 대응하는 공통 종이 벽체.
- `src/world/island-places.js`: 계류 표식, 수목 군락, 정원 조형물.
- `tests/place-identity.test.mjs`: 저장 배치 보존, 반복 적용, 오브젝트 수와 지오메트리 검사.

커밋과 원격 배포는 수행하지 않았습니다.
