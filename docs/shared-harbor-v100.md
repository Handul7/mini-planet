# v100 배 크기, 등대 섬, 공용 공간

## 반영 내용

- 탑승 가능한 어선의 기본 에셋 배율을 1.12로 변경했습니다. 기존 배보다 선형 크기가
  12% 커집니다. 저장된 개별 scale 값은 유지하며 기본 배의 최종 배율은 1.456입니다.
- 등대의 기존 넓은 곶을 비정형의 작은 섬으로 정리했습니다. 페이퍼컷 잔디 가장자리,
  모래 해안, 얇은 파도 테두리를 사용하며 남쪽 땅과의 연결은 주변 수역으로 분리합니다.
- 등대 앞 짧은 길 끝에는 나무 선착장을 연결했습니다. 해상 이동은 배로 하고,
  선착장과 해안으로 상륙하는 기존 조작을 유지합니다.
- 뒤편 기존 공용 정자를 중층 종이 지붕, 열린 입구, 양옆 벤치가 있는 쉼터로 재제작했습니다.
- 앞쪽 항구에는 접힌 지붕과 벤치, 구명환이 있는 대기 쉼터 하나를 추가했습니다.
  공용 공간은 정자와 항구 쉼터 두 곳이며, 새로운 개인 집은 추가하지 않았습니다.
- 공용 공간 입구도 가까운 도로 또는 시장/부두 길과 자동 연결됩니다. 이동, 회전,
  크기 변경 뒤에는 연결이 갱신되며 연석 입구도 함께 갱신됩니다.

## 코드 위치

- `src/world/public-spaces.js`: 정자 및 항구 쉼터의 코드 기반 에셋. 기존 종이 슬래브와
  층 지붕을 재사용하고 고정 부재를 병합하여 에셋당 메시 3~5개로 구성합니다.
  외부 에셋 다운로드, 추가 텍스처 및 실시간 조명은 없습니다.
- `src/main.js`: 어선 baseScale, 등대 섬 지형, 공용 공간 연결 및 QA 검사.
- `tests/public-spaces.test.mjs`: 에셋 지오메트리, 배율, 배치 보존, 마이그레이션,
  공용 진입로의 연결 대상 검사.

## 저장 보존

새 저장 키는 `HandulPlanet_layout_harbor_v25`이며 이전 v24 저장본은 남겨둡니다.
등대 위치나 해안이 수동으로 바뀌었거나 주변에 사용자 배치물이 있으면 섬 자동 변경은
건너뜁니다. 항구 쉼터 자리도 이미 점유돼 있으면 추가하지 않습니다.
기존 개인 집 위치 및 크기는 변경하지 않습니다. 초기화 없이 접속하면 적용됩니다.

실제 사용자 저장본은 오브젝트 26개에서 27개가 됐습니다. 기존 정자는 교체했으므로
개수는 그대로이고, 새 항구 쉼터만 한 개 추가됐습니다.

- 자동 테스트 98개 통과, 배포 전 설정 검사 통과.
- PC 1280x800 및 모바일 390x844: 전체 QA 통과, 캔버스 비어 있지 않음, 가로 넘침 없음.
- 기본 및 실제 저장 배치: 개인 집 6개 연결 유지, 공용 공간 2개 연결 및 진입로 통행 검사 통과.
- 도로 1,599개 표본: 충돌 0, 수역 침범 0.
- 등대 섬 외곽 28개 표본 전부 수역. 선착장 옆 해상 도보 진입 차단 및 상륙 가능 검사 통과.
- 등대 주변 보행 표본의 탈출 불가 지점 0. 어선 승선, 탑승 상태, 하선 검사 통과.
- 전체 행성 표본 수역 비율 42.9%. 행성 반지름과 기존 본도로 폭은 유지.
- 확인한 브라우저의 오류 및 경고 로그 없음.

표본 기반 검사는 임의의 사용자 배치나 모든 이동 경로를 보증하지 않습니다.
공용 공간은 현재 환경과 산책을 위한 장소이며 예약, 작업 배정 같은 새로운 서비스
기능을 추가한 것은 아닙니다. 커밋 및 원격 배포는 진행하지 않았습니다.
