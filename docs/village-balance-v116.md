# v116 유휴 공간과 마을 밀도 재검토

## 판단

현재 저장 배치를 앞면, 뒷면, 동서 측면, 남쪽 정원에서 확인했습니다. 집이 겹치는 문제보다는 시설과 녹지가 특정 장소에 몰리고, 그 사이가 긴 빈 잔디로 보이는 점이 문제였습니다. 행성 크기를 바꾸거나 건물을 늘리는 대신, 기존 시설의 분산과 소규모 녹지 연결로 보완했습니다.

전체가 같은 밀도일 필요는 없습니다. 앞마을은 활동 중심, 뒷마을은 조용한 주거지, 측면은 산책 구간, 장미는 독립된 정원, 등대와 남쪽 정원은 항해 목적지로 유지합니다.

## 확인한 문제와 반영

| 구역 | 확인한 모습 | 조정 |
| --- | --- | --- |
| 앞쪽 항구 | 대기 쉼터·노점·승선 시설이 왼편에 겹쳐 보임 | 노점을 오른쪽 부두 쪽으로 이동. 승선 지점과 쉼터는 유지 |
| 동쪽 율–앤 연결 구간 | 건물 사이에 길과 큰 잔디면만 보임 | 도로 아래 빈 잔디에 종이 수목 군락 1개와 비대칭 녹지 바닥 배치 |
| 서쪽 자비스–루드비히 연결 구간 | 가로등만 잔디 한가운데 남아 주변이 황량함 | 길 바깥에 수목 군락 1개와 녹지 바닥 배치. 가로등과 산책 구간이 함께 읽히도록 구성 |
| 뒤편 정자 주변 | 소나무가 정자와 집 사이에 붙어 실루엣이 집중됨 | 기존 소나무를 루드비히 쪽 서북 해안 여백으로 이동 |
| 남쪽 정원 | 수목 군락 3개가 순환길 한쪽 테두리에 집중됨 | 1개를 반대쪽 바깥 잔디로 이동. 중앙 조형물과 순환길은 비워둠 |

새 오브젝트 파일, 텍스처, GLTF, 라이브러리는 추가하지 않았습니다. 녹지 바닥은 기존 편집 가능한 `grass`, 수목은 기존 `paperGrove`를 사용합니다.

## 그대로 유지한 구조

- 행성 반지름 7.47, 지름 14.94.
- 표면 4,096개 표본 기준 육지 57.4%, 수역 42.6%.
- 여섯 집의 위치·방향·크기. 가장 가까운 집 중심 간 구면 거리 약 3.497 장면 단위.
- 도로 폭과 노선, 주택 진입로, 장미의 위치와 독립된 접근로.
- 등대 섬, 양쪽 선착장, 배 위치, 항해 경로와 바다 도보 진입 제한.
- 앞마을의 분수 광장, 게시판, 뒷마을 정자 등 주요 기준점.

남은 잔디와 바다는 모두 시설로 채우지 않았습니다. 장미를 알아보기 위한 여백, 집의 외곽선을 구분하는 간격, 이동과 항해에 필요한 시야를 유지하기 위한 선택입니다. 이번 조정은 대규모 도시화가 아니라 기존 소규모 마을의 밀도 균형 보완입니다.

## 저장 배치 보호

`migrateVillageBalance`는 기본 배치와 위치·방향·크기·색상이 일치하는 소품만 옮깁니다. 직접 옮기거나 삭제한 소품은 원래 위치로 복원하지 않습니다. 집이나 연결 골목을 수정했거나, 예정된 녹지 자리에 별도 오브젝트·길·잔디가 있으면 자동 보강을 건너뜁니다. 큰 사용자 녹지의 내부도 보수적인 구면 범위로 보호합니다.

저장 배치는 기존 백업 절차로 원본을 보관한 뒤 v116을 한 번 적용합니다. 반복 로딩 시 녹지가 중복 생성되지 않습니다. 모든 종류의 임의 사용자 배치까지 미적 균형을 자동 보증하는 것은 아닙니다.

## 검증과 비용

- 자동 테스트 283개 통과. 새 테스트 8개는 변경 범위, 멱등성, 사용자 편집 보호, 반올림된 저장 좌표, 백업 후 저장 순서를 확인합니다.
- 기본 배치와 실제 저장 배치 모두 겹침·문 앞 장애물·집 소유자 오류 없음.
- 도로 12개, 2,430개 표본: 충돌 0, 수역 침범 0.
- 집 진입·왕복, 승하선, 항구–등대–남쪽 정원 왕복 검사 통과. 주변 보행 표본에서 갇히는 지점 없음.
- 1280×900 데스크톱과 390×844 모바일 크기에서 화면 확인. 캔버스 표본 색상 44개/30개, 가로 넘침 없음, 콘솔 오류·경고 없음.
- 편집 소품 29개 → 31개. 녹지 바닥 경로 2개 추가.
- 전체 장면 메시 569개 → 581개, 재질 배치 571개 → 583개, 그림자 생성 메시 246개 → 252개. 이는 장면 구성 수이며 실제 한 프레임의 draw call은 시점과 그림자 갱신 시점에 따라 다릅니다.
- 정적 배포본 검사 통과: 94개 파일, 약 3.56 MiB. v115의 지연 로딩과 자동 화질 최적화 유지.

기능 검사 점수는 미적 완성도 점수가 아닙니다. 제 판단으로는 주요 시설을 더 늘리지 않고, 혼잡한 항구를 나누고 측면의 빈 구간에 작은 목적성을 주는 정도가 현재 스타일과 경량화 방향에 적절합니다.

수정 파일: `src/main.js`, `src/boot.js`, `index.html`, `sw.js`, `tests/village-balance.test.mjs`. 커밋과 외부 배포는 하지 않았습니다.
