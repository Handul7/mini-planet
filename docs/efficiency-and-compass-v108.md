# v108 효율화와 장소 나침반

작성일: 2026-09-11. v107의 배치와 페이퍼컷 표현을 유지한 로컬 개선입니다.

## 방향 기준

- 장미는 `NORTH_POLE = (0, 1, 0)`에 고정되어 있어 실제 북극점입니다. 하늘에 떠 있는 북극성 자체가 아니라 북극 방향의 지상 기준물입니다.
- 기본 등대는 정규화된 `(0, -0.505, -0.863)` 위치, 남위 약 30.3도의 섬입니다. 정남극 `(0, -1, 0)`과 다르며, 이번에 등대나 섬을 이동하지 않았습니다.
- 작은 방향계의 붉은 N은 장미 방향, S는 그 반대의 정남쪽입니다. 파란 표식은 별도로 실제 등대 방향을 가리킵니다. 등대를 무조건 S에 붙이면 위치에 따라 잘못 안내하므로 두 방향을 분리했습니다.
- 탐험에서는 플레이어 위치, 관제에서는 카메라 아래쪽 행성 표면을 기준으로 카메라 방향에 맞춰 회전합니다. 클릭 이동이나 자동 항해 기능은 추가하지 않았습니다.
- 편집으로 등대를 옮기거나 삭제하면 현재 집 좌표를 따라갑니다. 목표가 없거나 정확히 반대편 극점이라 방향이 결정되지 않으면 임의의 방향을 표시하지 않습니다.

## 줄인 처리

1. `homeDoorDir`: `updateMatrixWorld(true)`로 집 전체 하위 오브젝트를 강제 갱신하던 호출을 제거했습니다. 번들 Three.js의 `localToWorld`가 조상과 해당 노드의 행렬을 이미 갱신하므로 문 좌표는 그대로 계산됩니다. 장식 100개, 60회 호출 회귀 검사에서 이전 방식의 하위 갱신 6,000회를 제거하고 좌표 일치를 확인했습니다. 이는 해당 함수의 호출 수 비교이며 전체 프레임 속도 향상률은 아닙니다.
2. 플레이어 복구 판정: 한 프레임에 두 번 검사하던 충돌 여유를 한 번 계산해 재사용합니다. 1,000개 방향에서 기존 판정과의 동등성을 검사했습니다.
3. 라벨 장애물: 매 프레임 UI 선택자를 다시 검색하지 않고 DOM 참조를 재사용합니다. 패널 열림 상태와 실제 표시 영역은 계속 확인합니다. 나침반도 라벨 회피 영역에 포함합니다.
4. 장식 움직임: 행성 뒤편에 가려진 집의 깃발과 장미 애니메이션 계산을 건너뜁니다. 에이전트 이동, 충돌, 날씨 상태는 중단하지 않습니다. 다시 보이면 현재 시간 기준으로 움직임을 계산합니다.
5. 나침반: 별도 타이머나 RAF 없이 기존 루프에서 최대 20Hz로 갱신합니다. 각도 변화 0.5도 미만이면 CSS를 다시 쓰지 않습니다. 방향 경계 179도/-179도에서도 한 바퀴 돌아가지 않도록 처리했습니다.

## 화면 정리

- 나침반은 날씨 아래 작은 원형 표시로 배치하고 상세 패널과 편집 모드에서는 숨깁니다. 모션 감소 설정에서는 회전 보간을 끕니다.
- 521~700px에서 게시판 버튼이 편집 버튼과 겹치던 반응형 기준을 520px로 맞췄습니다.
- 360px 이하에서는 상단 안내 문구를 접고 폭을 줄여 도구 열과 분리했습니다.

- 기본 및 현재 저장 배치의 `qaReady=pass`. 다섯 집 실제 이동 함수 왕복과 등대 승선/상륙/현관 왕복/귀항 검사 통과.
