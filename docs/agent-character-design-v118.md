# v118 에이전트 캐릭터 디자인

## 범위

사용자 소유의 RPG 캐릭터 시트를 참고하여 여섯 에이전트의 의상, 머리, 대표 도구를 변경했다. 기존 둥근 3D 미니어처 비율과 무광 페이퍼컷/툰 재질은 유지했다. 지형, 집, 도로, 카메라, 이동 및 애니메이션 로직, 서비스 연결, 방문자 캐릭터는 이번 변경 범위에서 제외했다.

참고 자료: `/Users/handul/Documents/New project/asset-delivery/rodi-art-direction-20260912-v1/images/`의 `01_rodi_8views_v2.png`부터 `06_argos_8views.png`까지. 시트는 디자인 참고용이며 런타임 모델이나 스프라이트로 배포하지 않는다.

## 디자인 반영

| 에이전트 | 반영한 특징 |
| --- | --- |
| 로디 | 남색 열린 코트, 크림색 셔츠/소매, 가죽 벨트, 별 장식, 수리된 소리굽쇠 지휘봉 |
| 자비스 | 청동 인간형 자동인형, 원형 렌즈/귀 디스크, 연미복, 흰 크라바트와 소매, 가슴 다이얼/회중시계 |
| 율 | 검은 낮은 묶음머리, 청록색 겹옷과 넓은 소매, 크림색 옷깃, 귀 결정, 소리굽쇠 |
| 루드비히 | 회색 머리, 둥근 안경, 학자 코트/목도리, 잠금장치 있는 닫힌 책, 가방 |
| 앤 | 붉은 양갈래 땋은 머리, 잎 장식 밀짚모자, 초록 겹치마와 크림색 속치마, 붓/작은 병 |
| 아르고스 | 보라색 뾰족 후드, 은빛 머리, 감은 눈, 손을 가린 소매, 공중의 눈 두 개, 발치의 작은 청동 부엉이 |

원화의 사실적인 인체 비율과 세밀한 자수는 복제하지 않았다. 행성에서 읽히는 실루엣, 색, 대표 소품을 기존 스타일에 맞춰 번역했다.

## 구현 위치

- `src/main.js`: `addAgentAccessories`, 개발용 캐릭터 진단 정보.
- `index.html`, `src/boot.js`, `sw.js`: 캐시 버전 118.
- `tests/agent-character-design.test.mjs`: 몸체/리그 유지, 대표 소품, 재질, 유효 지오메트리, 걷기, 방문자 비변경 검사.
- `tests/character-fixture.mjs`: 실제 프로덕션 팩토리를 테스트와 시각 검토에서 공유.
- `tests/character-review.html`, `tests/character-review.mjs`: 정면/측면/뒷면과 걷기 확인용 로컬 화면. 공개 배포본에는 포함하지 않는다.

## 가벼움과 검증

- 새 의존성, 외부 모델, 이미지 텍스처 다운로드 없음.
- 여섯 캐릭터 합계 삼각형: 24,714 → 25,348, 약 2.6% 증가.
- 동일 테스트 팩토리의 배치 후 메시: 175 → 213. 입체 의상으로 렌더 호출은 늘었으므로 비용이 완전히 같다는 의미는 아니다. 상태 표시 오브젝트는 이 비교에서 제외했다.
- 캐릭터당 테스트 상한: 메시 45개, 삼각형 6,000개. 실제 모바일 기기의 FPS나 발열을 측정한 결과는 아니다.
- 전체 자동 테스트: 296개 통과. 배포 전 검사와 정적 배포 산출물 검사 통과.
- 정적 배포본: 94개 파일, 3.56 MiB.
- 브라우저: 1280px 데스크톱, 390px 모바일 화면 확인. 캐릭터 검토 캔버스의 복수 색상 픽셀과 애니메이션 진행 확인, 실제 행성 QA `pass`, 여섯 에이전트 모두 `rpg-paper-118` 적용 확인. 확인한 콘솔 오류 없음.
- 커밋 및 원격 배포는 수행하지 않음. 기존 미커밋 작업을 유지함.
