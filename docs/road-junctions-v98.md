# v98 도로 연결 개선

## 적용 범위

- 중앙 운영 코어를 가로지르던 십자 도로를 순환로와 네 방향 진입로로 변경.
- 로디 집의 충돌 영역 안으로 들어가던 도로 종점을 집 앞에서 종료.
- 항구 쪽 도로 끝의 바다 경계 침범을 없애도록 종점을 소폭 후퇴.
- 집 진입로 폭을 0.26에서 0.50 월드 단위로 조정. 본도로 0.90, 골목 0.70은 유지.
- 다른 도로, 집 진입로, 시장과 부두 통로가 만나는 곳의 연석을 개방.
- 길 추가, 복제, 삭제와 집 이동 후 진입로 및 연석 개구부를 다시 계산.

집 위치, 행성 크기, 에이전트 색과 시그니처, 기존 오브젝트 수는 변경하지 않았습니다.
등대 섬은 육지 도로망과 연결하지 않았으며 기존 배 이동 방식을 유지합니다.

## 저장 호환

현재 저장 키는 `HandulPlanet_layout_harbor_v24`입니다.
이전 v23 저장본은 삭제하지 않습니다. 기본 도로와 위치가 일치하는 교차로만
새 구조로 변환하고, 사용자가 바꾼 도로 또는 옮긴 코어와 집은 자동 변환하지 않습니다.
현재 사용자의 저장 배치도 오브젝트 26개를 유지한 상태로 검사했습니다.
재접속 후 적용되며 배치 초기화는 필요하지 않습니다.

## 검사

`roadClearanceState()`는 막힌 지점을 먼저 제외하지 않고 도로의 중앙과 좌우
보행 가능 가장자리를 모두 검사합니다. 실제 수역 판정도 별도로 확인합니다.
`qaRoadClearance`가 실패하면 브라우저의 전체 `qaReady`도 실패합니다.

기본 및 실제 저장 배치: 도로 9개, 1,599개 표본, 충돌 0건, 수역 침범 0건.
여섯 집 진입로 연결과 기존 입장, 수영 차단, 배 승하선 검사 통과.
원래 도로를 재현하면 중앙 코어와 로디 집 충돌을 검출하는 회귀 테스트를 포함합니다.
연석 분리, 사용자 편집 보존, 도로망 연결, 편집 후 갱신도 테스트합니다.

표본 검사는 모든 사용자 편집 결과나 모든 이동 경로를 보증하지 않습니다.
도로를 수정한 뒤에는 QA를 다시 실행해야 합니다.

기본 배치: `?dev=1&qa=1&qaView=dashboard`
저장 배치: `?dev=1&qa=1&qaLayout=saved&qaView=dashboard`
