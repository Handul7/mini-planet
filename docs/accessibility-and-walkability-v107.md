# v107 화면 가림 및 보행 접근성 개선

작성일: 2026-09-11
기준: v106 배치 검토 후속 확인. 이번 변경은 로컬 적용이며 커밋과 공개 배포는 하지 않음.

## 변경 내용

| 문제 | 적용 | 확인 결과 |
|---|---|---|
| 592px 화면에서 왼쪽 패널이 마을과 정자를 가림 | 900px 이하 팀 목록 기본 접힘. 521~900px에서는 하단 배치와 짧은 헤더 적용 | 592x784에서 후면 정자 확인. 팀 상세 열기와 닫기, 닫기 버튼 포커스 확인 |
| 집 테스트가 현관 순간 이동에 의존 | 다섯 집에 실제 이동 함수로 출발점-진입로-현관-출발점 왕복 검사 추가 | 기본 및 현재 저장 배치 모두 통과 |
| 등대 상륙 이후 현관 접근이 검증되지 않음 | 항해 검사에 상륙-현관-섬 부두 왕복 추가 | 과도한 충돌 영역을 실제로 발견하고 수정 후 통과 |
| 등대의 평평한 기단 주변까지 진입 금지됨 | 등대 충돌 반경 0.22에서 0.17라디안으로 조정. 모델의 고체 기단 반경 1.22와 행성 반지름 7.47 기준 | 고체 기단 차단 유지, 현관 앞 접근 가능. 배율 0.7/0.86/1 수치 회귀 검사 추가 |
| 장미 공간이 집 앞마당처럼 읽힘 | 기존 원형 포장을 서쪽으로 펼친 비대칭 7점 공간으로 변경 | 집과 장미의 위치 변경 없이 접근 공간 분화. 모든 각도의 실루엣 분리를 보장하지는 않음 |

## 보행 검사 범위

- 육상 다섯 집: Rodi, Jarvis, Yul, Ludwig, Anne. 시작 위치 설정 이후 중간 지점으로 순간 이동하지 않음.
- 실제 `tryMovePlayerOnSurface` 함수와 현행 육지/충돌 판정을 사용함. 바다를 도보로 통과하도록 판정을 완화하지 않음.
- Argos: 주 부두까지 도보, 승선, 등대 섬 항해, 하선, 현관까지 왕복, 재승선, 귀항, 육지 복귀의 10단계 통과.
- 경로 탐색은 이동 가능한 지표면 기준이므로 잔디를 지날 수 있음. 모든 구간에서 도로 중심선을 따라간다는 검사는 아님.
- 이는 실제 이동 로직에 대한 자동 검사임. 사람이 모든 경로를 키보드나 터치로 직접 완주했다는 의미는 아님.
- 검사 종료 및 실패 시 플레이어와 배 상태를 복구함. 진단 결과의 `distance` 단위는 라디안이며 월드 거리로 보려면 7.47을 곱함.

## 저장 배치 보호

장미 변경은 `rose.quiet-garden` ID와 알려진 기존 원형 포장에만 적용함. 사용자가 변형한 포장은 유지하며 집 좌표와 크기, 도로 폭, 육해 비율, 오브젝트 수는 변경하지 않음.

v106 마이그레이션 뒤 v107 변경을 적용하며, 변경 직전 상태를 `before-composition-v107` 사유로 백업함. 기존 v106 완료 표식과 독립적인 v107 표식을 사용함. 백업 실패 시 기존 배치를 유지하고 반복 실행 시 중복 공간을 생성하지 않음.

## 검증

- Node 테스트 174개 통과.
- 배포 전 검사 통과: 에이전트/서비스 스키마, 로컬 GLTF, Three.js, 폰트, 캐시 버전 및 JavaScript 문법.
- 정적 배포본 검사 통과: 공개 파일 86개, 약 3.50 MiB. 새 라이브러리나 외부 에셋 추가 없음.
- 390x844, 592x784, 1280x800 브라우저 화면 확인. 가로 넘침 없음, 캔버스 렌더링 확인.
- 기본 배치 및 현재 저장 배치의 `qaReady=pass`. 데스크톱 확인 시 수집된 콘솔 경고/오류 없음.

## 남은 범위

- 남극의 자연 여백은 v106 방침대로 유지함. 이번 변경은 행성 전체를 도시화하거나 축소하는 작업이 아님.
- 장미와 로디 집은 일부 방향에서 겹쳐 보임. 완전한 분리가 필요하면 별도의 좌표 변경 검토가 필요함.
- 임의로 편집한 모든 배치와 모든 모바일 실기기를 보장하지 않음.
- Hermes 실연결과 공개 배포는 이번 검증 범위 밖임.
